What is AX?

AX (github.com/google/ax) is a declarative orchestrator built to run millions of sandboxed autonomous agent workloads per Kubernetes cluster on top of Agent Substrate.

Task
an isolated gVisor sandbox running your agent container with CPU & memory limits
Workspace
Git repositories, inline guidance files (AGENTS.md), MCP servers, and skills pre-wired in /workspace
Model
LLM provider + model identifier + Kubernetes Secret binding (gemini-api-secret)
Why not CRDs?
millions of short-lived agent tasks overwhelm Kubernetes etcd; AX stores specs in PostgreSQL and overlays live Actor status from Agent Substrate
Zero-compute idle
tasks start Suspended; ax suspend checkpoints /workspace to object storage and frees 100% of worker CPU/RAM until ax resume

Inside the gVisor Sandbox
